The 64 KB NEFF kernel binary is reloaded over PCIe on every invocation. The actual computation (10.7 µs) is negligible — 99.999% of wall time is dispatch overhead. The CPU fallback does the same work in 8 µs with zero device dispatch.

Why XLA wins

XLA traces the entire model graph once and compiles a single NEFF that fuses all linear ops. The NKI patches split this into 20 separate NEFFs — each reloading a 64 KB binary — for the same shapes that XLA handled in one shot.

The linear shapes are tiny: M=40, K∈{16–192}. These are well below the [128×512] minimum needed to amortize Tensor Engine startup cost.

Finding: Why attention_tkg was also ruled out

The aten::bmm calls in the profile (4.5/run, 7.6 ms avg) are not QKV attention — they are Wigner D-matrix rotations:

EquiformerV3's "attention" is a graph-based scatter softmax over edges, not a sequence-level Q·KT·V. attention_tkg (transformer token-generation with KV-cache) is architecturally the wrong kernel. Each Wigner bmm is only 23 KB of data — still below dispatch amortization threshold.

Core Lesson

NKI Dispatch Cost Dominates Small Models

Every NKI kernel call from Python host code reloads a ~64 KB NEFF binary over PCIe. This costs ~1.2 seconds per call, independent of tensor size or batch size. For this NaCl unit cell (40 edges), compute completes in nanoseconds, but dispatch pays the full 1.2s.

XLA's torch.compile(backend='neuron') wins because it traces the whole model graph into one NEFF — one reload, all ops fused, zero per-op dispatch cost.

NKI pays off when: the kernel is large enough (typically tens of KB to MB of data), called in a tight device-side loop, or when it replaces an op that XLA cannot already fuse (dynamic shapes, custom scatter patterns).

What Would Actually Help

StrategyWhy it would work
Larger batches (multi-molecule) Once M ≥ 128 across batched atoms, Tensor Engine saturates and per-NEFF overhead amortizes. At B=4 molecules × 39 edges = 156 rows (M_pad=256), NKI gets 2 tiles — first fair comparison point.
NKI inside XLA fusion Register an NKI kernel as a custom XLA op so it compiles into the same NEFF as the rest of the graph. Only one PCIe reload for the entire forward pass.
Fused Wigner rotation kernel Fuse both so3.py bmm calls + their normalization into one NKI kernel — halves dispatch count for that block.
RadialFunction fusion The [40,128]→[32]→[32]→[192] MLP is called 4× per forward. Fusing all 3 linears + SiLU into one NKI kernel saves 2 HBM round-trips and 2 PCIe reloads.
